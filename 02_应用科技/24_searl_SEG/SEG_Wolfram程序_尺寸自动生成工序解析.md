## 三、核心几何约束方程组（所有方案的公共骨架）

从 `各参数方案.nb` 的 `conds` 提取，5 套方案共用以下 12 类约束：

```mathematica
(* 1. 定子轴向高度 = 滚筒高度 + 附加系数×分段数 *)
Bh1 == (Yh1 + a1) b1
Bh2 == (Yh2 + a2) b2
Bh3 == (Yh3 + a3) b3

(* 2. 定子外径 = 滚筒数 × 稀疏因子 × 滚筒半径 / 2 *)
BR1 == num1 n1 Yr1 / 2
BR2 == num2 n2 Yr2 / 2
BR3 == num3 n3 Yr3 / 2

(* 3. 滚筒体积 = π r² h *)
Yv1 == Yr1^2 Pi Yh1
Yv2 == Yr2^2 Pi Yh2
Yv3 == Yr3^2 Pi Yh3

(* 4. 定子环体积 = π(R² - r²) h *)
Bv1 == (BR1^2 - Br1^2) Pi Bh1
Bv2 == (BR2^2 - Br2^2) Pi Bh2
Bv3 == (BR3^2 - Br3^2) Pi Bh3

(* 5. 环间嵌套约束：内环外径 + 两侧间隙 + 滚筒直径 = 外环内径 *)
su1 + sd1 + 2 Yr1 + BR1 == Br2
su2 + sd2 + 2 Yr2 + BR2 == Br3

(* 6. 默认间隙/壁厚 *)
su1==1; sd1==1; su2==1; sd2==1; sd3==1

(* 7. 默认稀疏因子 *)
n1==1; n2==1; n3==1

(* 8. 默认滚筒数（经典 Searl 配置） *)
num1==12; num2==22; num3==32
```

**求解引擎**：`Reduce[And @@ conds, Reals]` —— 符号约束求解器，给定一组已知量，反解其余未知量。

## 五、主交互程序（index.nb）的实时生成工序

从 `index-滑动条备份.nb` 还原的主循环逻辑：

```mathematica
(* 滑动条输入：Bm1,Bm2,Bm3 = 各环磁场强度；Brou = 基准；Bh1 = 定子高 *)
Brr = Solve[(BR1^2 - Brr^2) Pi Bh1 == Bm1/Brou, Brr]   (* 反解滚筒内径 *)
Br2 = Solve[(BR2^2 - Brr^2) Pi Bh1 == Bm2/Brou, Brr]
Br3 = Solve[(BR3^2 - Brr^2) Pi Bh1 == Bm3/Brou, Brr]

orbit1 = (BR1 + Br2)/2    (* 轨道半径 = 相邻环中点 *)
orbit2 = (BR2 + Br3)/2
```

**交互工序**：
1. 用户拖动 Manipulate 滑块 → 改变 `Bm1/Bm2/Bm3/Brou/Bh1` 等参数
2. 程序对每个环执行 `Solve` 反解滚筒内径 `Brr`（即 `r`）
3. 由 `BR`（定子外径，由 `num×n×Yr/2` 决定）和 `Br`（解出）算出轨道中点 `orbit`
4. 3D 图形（Graphics3D）实时重绘三环 + 滚筒阵列

> **与"方案生成"系列的区别**：`各参数方案.nb` 用 `Reduce` 做**离线全量符号求解**（给定体积→全尺寸）；`index.nb` 用 `Solve` 做**在线单变量反解**（拖滑块→实时半径）。两者共享同一几何内核，前者是设计态，后者是预览态。
