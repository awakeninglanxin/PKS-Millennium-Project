# 传统大盘预警系统 · 详细技术说明

> 文件：`traditional_indicators.py` ｜ 版本 v1.3 ｜ 2026-08-03
> 定位：**经典技术分析预警**——上证指数真实数据（腾讯行情 API）的 MA/MACD/RSI/BOLL/KDJ 综合研判，输出操作指令与数据依据

---

## 一、系统定位

传统预警系统与分形预警系统形成**方法对照**：

| 维度 | 分形预警 | 传统预警 |
|------|---------|---------|
| 数据 | 多股票面板（模拟/通达信） | **上证指数单标的真实数据** |
| 方法 | 分形数学（MF-DFA/簇跳率） | 经典技术指标（MA/MACD/RSI/BOLL/KDJ） |
| 视角 | **结构**是否瓦解 | **趋势**是否转弱 |
| 信号特点 | 提前（中位 15-60 天） | 滞后（趋势确认后） |
| 输出 | 结构 regime 预警 | 趋势方向 + 超买超卖 |

**两套系统同屏对照的意义**：趋势先行转弱（传统），但结构未必瓦解（分形）——两个视角互为校验，比单一系统可靠。

## 三、指标函数清单（11 个函数）

### 3.1 指标计算层

| 函数 | 行号 | 公式/参数 | 说明 |
|------|------|-----------|------|
| `sma(x, n)` | 49 | 简单移动平均 | 前 n-1 位为 NaN |
| `ema(x, n)` | 59 | 指数移动平均 $EMA_t = k x_t + (1-k) EMA_{t-1}$，$k=2/(n+1)$ | MACD 基础 |
| `macd(close, 12, 26, 9)` | 74 | DIF=EMA12−EMA26；DEA=EMA(DIF,9)；HIST=(DIF−DEA)×2 | 动能指标 |
| `rsi(close, 14)` | 84 | $RSI = 100 - 100/(1+RS)$，RS=平均涨/平均跌（Wilder 平滑） | 超买超卖 |
| `boll(close, 20, 2)` | 107 | 中轨=MA20；上下轨=MA20±2σ；%B=(C−下轨)/(上轨−下轨) | 波动通道 |
| `kdj(high, low, close, 9, 3, 3)` | 122 | RSV→K→D→J（J=3K−2D） | 摆动指标 |

### 3.2 事件检测层（v1.2 新增，K线图标记用）

| 函数 | 行号 | 检测逻辑 |
|------|------|----------|
| `detect_boll_events(dates, close, boll_up, boll_low, lookback=120)` | 267 | **突破上轨**（今收>上轨 且 昨收≤上轨）；**跌破下轨**（今收<下轨 且 昨收≥下轨） |
| `detect_macd_events(dates, dif, dea, lookback=120)` | 288 | **金叉**（DIF 上穿 DEA）；**死叉**（DIF 下穿 DEA） |

### 3.3 预警层

| 函数 | 行号 | 作用 |
|------|------|------|
| `traditional_alert(...)` | 145 | 综合判定 → 操作指令/仓位/依据 |
| `analyze_traditional(kline=None)` | 313 | **全量汇总**：拉数据 → 算全部指标 → 事件检测 → 预警 → 返回完整 dict |

## 四、预警判定逻辑（traditional_alert）

### 4.1 信号计数

```python
bear_cnt = 空头信号数（死叉/空头排列/跌破/下轨）
bull_cnt = 多头信号数（金叉/多头排列/突破/上轨）
over_buy  = RSI>70 或 J>100 或 %B>1
over_sell = RSI<30 或 J<0 或 %B<0
```

### 4.2 分级判定表（v1.3）

| 条件 | 级别 | 操作指令 | 建议仓位 | 典型场景 |
|------|------|---------|---------|---------|
| bear_cnt ≥ 3 | 🔴 红 | **撤退 / 大幅减仓** | ≤20% | MA60下方+死叉+空头排列共振 |
| bear_cnt = 2 | 🟠 橙 | **减仓** | ≤40% | 双空头信号共振 |
| bear_cnt = 1（无超买） | 🟡 黄 | 减仓或观望 | 50-60% | 单空头信号 |
| 超买 + bear_cnt ≥ 1 | 🟠 橙 | 减仓 | ≤50% | 高位风险聚集 |
| 超卖 + bull_cnt ≥ 1 | 🟡 黄绿 | 轻仓试探 | 30-50% | 超跌反弹机会 |
| bull_cnt ≥ 2 | 🟢 绿 | 持有/增持 | 60-80% | 金叉+多头排列 |
| 其他 | 🟢 绿 | 持有 | 50-70% | 中性 |

### 4.3 输出字段（v1.3 升级）

```python
{"level": "橙", "color": "orange",
 "msg": "传统指标: 双空头信号 (减仓)",
 "action": "减仓至 40% 以下", "pos": "≤40%",
 "suggestion": "出现2个空头信号共振, 趋势转弱确认中 → 建议减仓至4成以下, 反弹减磅",
 "signals": ["收盘跌破MA60 (中期空头)", "MA5 < MA20 (短期空头排列)"],
 "rationale": ["收盘价 3810 < MA60 4024 (偏离 -5.3%) → 中期趋势转空",
               "MA5 3818 < MA20 3882 → 短期均线空头排列",
               "RSI(14)=40 中性区间", "%B=0.27 处于布林带内", "KDJ J=48 中性"]}
```

> **rationale（分析依据）是 v1.3 的核心升级**：每条信号都带具体数值与解释，不再是无依据的笼统建议。
