> 文件：`fractal_analysis.py` ｜ 版本 v1.3 ｜ 2026-08-03
> 定位：**分形数学预判大盘**——通过多重分形特征 + 锚定聚类 + 簇跳率监测市场结构瓦解信号

---

## 一、系统定位与核心逻辑

分形预警系统回答一个问题：**当前市场的"结构"是否正在瓦解（崩盘前奏）？**

```
个体股票收益率
   ↓ 分形特征提取（MF-DFA 谱 / Hurst / Hill 尾指数 / 分布特征）
每只股票 → 特征向量（16维）
   ↓ 锚定聚类（首窗口拟合簇中心，后续窗口分配）
股票被分到不同"结构簇"（同簇 = 行为模式相似）
   ↓ 滑动窗口对比
簇跳率 = 股票从上一窗口的簇跳向另一簇的比例
   ↓ 阈值/z-score 判定
预警信号：绿(稳定) → 黄(松动) → 红(瓦解/撤退)
```

**核心实证结论**（元宝对话全盘阅读 + 本系统回测验证）：
- 簇跳率在崩盘前 **中位提前 15-60 天** 飙升（真实市场 20%→56%+）
- 纯 Hurst 指数滞后 5 天、漏报 47.5%——**单一分形维度不可用**
- 分形签名让聚类信息量提升 **12 倍**（NMI 0.03 → 0.38）

## 三、核心算法详解

### 3.1 MF-DFA（多重分形去趋势波动分析）

5 步标准算法：
1. **累积离差**：$Y(i) = \sum_{k=1}^{i}[r_k - \bar{r}]$
2. **分箱**：$N_s = \lfloor N/s \rfloor$ 个等长窗口（尺度 s ∈ {4,8,16,32,64,128,256}，两端各一遍）
3. **去趋势**：每窗 m 阶多项式拟合，算方差 $F^2(s,v)$
4. **q 阶波动**：$F_q(s) = \left\{ \frac{1}{2N_s}\sum_v [F^2(s,v)]^{q/2} \right\}^{1/q}$
5. **回归**：$\ln F_q(s)$ vs $\ln s$ 斜率 = $h(q)$

**解读**：h(q) 随 q 变化（谱宽 Δh 大）= 多重分形结构复杂；Δh 收窄 = 结构退化（崩盘前兆）。

### 3.2 锚定聚类（AnchorClusterer）

```python
anchor = AnchorClusterer(n_clusters=(3,5,8), random_state=42)
anchor.fit(首窗口特征)      # KMeans 拟合簇中心 (n_init=10 可复现)
labels = anchor.predict(后续窗口特征)  # 只做最近中心分配
```

**效果**：正常期特征漂移小 → 归属稳定 → 簇跳率低；崩盘期结构剧变 → 大量换簇 → 簇跳率高。

### 3.3 簇跳率与预警阈值

```
CJR_t = (窗口 t-1 与窗口 t 之间簇归属变化的比例, Hungarian 对齐后)
```

**预警判定表**（alert_engine）：

| 条件 | 级别 | 操作指令 | 建议仓位 |
|------|------|---------|---------|
| fine>55% 或 mid>55% | 🔴 红 | **撤退/大幅减仓** | ≤20% |
| mid>40% 或 fine>45% | 🟠 橙 | **减仓观望** | ≤40% |
| mid>25% | 🟡 黄绿 | 结构活跃，正常分化 | 50-60% |
| mid<25% | 🟢 绿 | 结构稳定 | 60-80% |
| + Δh<0.5（叠加） | 降档 | 结构退化，警惕风格切换 | — |
| + Hurst<0.45（叠加） | 提示 | 均值回归主导，勿追涨 | — |

**输出字段**：`{level, color, msg, suggestion, action, pos, rationale}`（v1.3 新增 action/pos/rationale）

## 四、回测实证结果（backtest.py）

### 4.1 合成数据（40 只 × 800 日，植入 3 崩盘日）

| 指标 | 值 |
|------|-----|
| 簇跳率基线 | 34.6%（修复后） |
| **检出率** | **67%**（2/3） |
| **平均提前** | **60 天** |
| 误报率 | 17% |
| 纯 Hurst 基线检出率 | **0%** |

### 4.2 真实数据（上证指数 18 大跌日，20 只权重股面板）

| 指标 | 值 |
|------|-----|
| 簇跳率基线 | 20.3% |
| **检出率** | **22%**（4/18） |
| **平均提前** | **35 天** |
| 误报率 | **0%** |

### 4.3 结论

1. 簇跳率确实具备**提前预警**能力（合成 60 天 / 真实 35 天）
2. 显著优于纯 Hurst（检出率 0%）
3. 真实数据检出率偏低受限于：仅 20 只样本、500 日历史、大跌日定义（-1.8%）较宽 → **扩大样本池可提升**
