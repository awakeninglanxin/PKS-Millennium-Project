## 一、金融同位体映射表（Mandelbrot → 股票）

| Mandelbrot 概念 | 金融同位体 |
|----------------|-----------|
| M 集芽苞锚（Farey 头尖） | 每只股票（或板块指数） |
| 径向/角向迭代数 | 收益率序列 |
| 360° FFT 谱 | MF-DFA h(q) 谱 |
| Farey (p,q) 验证 | HMM regime 当 GT |
| 缩放层级 L0~L7 | K 线 1min / 1h / 1d 三粒度 |

**⚠️ 铁律避坑**：别碰"把 K 线硬映射成 M 集迭代"（c 是实轴一维游走，M 集结构是复平面 2D，数学无依据）。正确做法是**抽取"分形签名"做聚类**，不是把价格塞进迭代公式。

## 二、5 条思维迁移操作（M 集聚类 → K 线）

1. **地标锚定**：Farey 头尖 → K 线顶底分型/量突增/布林松脱（拒绝均匀盲扫）
2. **多投影签名**：径向+角向+密度+周期 → 收益率+成交量+盘口+MF-DFA 谱
3. **变换域读机制**：FFT 读 p/q → MF-DFA 谱+尾部 α+Hurst（时域长得像≠同机制）
4. **多尺度切树**：L0→L7 → K 线 1min/1h/1d 三粒度 Ward 切树（找假同质簇）
5. **GT 校验**：Farey → 行业标签 + HMM regime 算 ARI

## 三、消融实验（64 只合成票：8 行业×8 只）—— 分形签名值多少钱？

| 配置 | 指标 | NMI | 结论 |
|------|------|-----|------|
| A：纯收益率 | 0.031 | ❌ 接近随机 |
| **B：+h(q) 谱 + tail α** | **0.379** | ✅ **+12 倍** |
| C：+wavelet + H | 0.367 | 与 B 相当 |
| D：+anchor | 0.367 | 与 B 相当 |
| E：三粒度融合 | 0.310（ARI 0.367） | 对 regime 对齐最有用 |

**核心结论：纯收益率聚类≈随机（NMI=0.03）；加分形签名 NMI 翻 12 倍；多粒度融合对 regime 对齐最有用。**

## 四、B.T.S.E. v2 管线（⭐ 崩盘预警完整实现）

### 4.1 管线架构

```
真实行情（akshare / westock-data 腾讯自选股）

   ↓
簇跳率 = 跨窗簇归属变动比例（预警信号）
   ↓

```

## 八、方法论缺陷与诚实边界（重要）

1. **不能预测点位**：输出是"结构 regime 预警"，不是"明天涨多少"
2. **LTCM 教训**：0→1 外生冲击（黑天鹅）分形模型一样跪
3. **参数敏感**：120日窗/20日步长需回测滚动验证
4. **GT 是代理**：HMM regime 不是真值，用行业标签交叉验证
5. **聚类≠预测**：簇结构是描述性的，预警信号需严格回测才能实盘
