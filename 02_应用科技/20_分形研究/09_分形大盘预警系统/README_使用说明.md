## 一、这是什么

一套**分形数学预判大盘**的完整实现——通过 MF-DFA 多重分形谱 + Hurst + Hill 尾指数 + Ward 聚类 + **簇跳率预警**，监测 A 股市场结构是否正在瓦解（牛/熊/崩盘前奏）。

**核心实证结论**（来自元宝链接全盘阅读）：
- 簇跳率在崩盘前中位 **提前 15 天** 飙升（正常 24-46% → 崩盘窗 56-62%）
- 纯 Hurst 不可用（滞后 5 天、漏报 47.5%）
- 分形签名让聚类信息量提升 **12 倍**（NMI 0.03 → 0.38）

## 五、接通达信真实数据

1. 修改 `app.py` 顶部：`TDX_MODE = "tdx"`
2. 在 `fetch_tdx_panel()` 中实现通达信 K 线拉取：
   - 使用通达信 MCP `tdx_kline`（前复权）
   - 或 westock-data / akshare 拉沪深300权重股日K
3. 返回格式：`{代码: 对数收益率ndarray}`

```python
# 示例（伪代码）
from tdx_connector import get_kline
panel = {}
for code in hs300_codes:   # 沪深300成分股
    k = get_kline(code, period="day", count=500)
    close = np.array([r[4] for r in k])
    panel[code] = np.diff(np.log(close))
```

## 九、回测实证结果（v1.2 新增，backtest.py）

**锚定聚类改进**：初版 Ward 每次重聚导致簇跳率基线过高（60-90%，无区分度）。改为 **AnchorClusterer**（首窗口 KMeans 拟合簇中心，后续窗口只做最近中心分配）后：

| 场景 | 簇跳率基线 | 检出率 | 平均提前 | 误报率 |
|------|-----------|--------|----------|--------|
| 合成数据（3 崩盘日植入） | 34.6% | **67%** (2/3) | **60 天** | 17% |
| 真实数据（上证 18 大跌日） | 20.3% | 22% (4/18) | **35 天** | 0% |
| 纯 Hurst 基线（对照） | — | **0%** (0/3) | — | — |

**结论**：
1. 簇跳率确实具备**提前预警**能力（合成提前 60 天、真实提前 35 天）
2. 显著优于纯 Hurst 基线（后者检出率 0%）
3. 真实数据检出率 22% 偏低——受限于 20 只样本股 + 500 日历史 + 大跌日定义（-1.8%）较宽
4. 预警信号是"结构瓦解预警"而非点位预测，需与基本面/DCF 组合使用

**关键算法改进**：特征相关 0.95-0.99（稳定）但 Ward 重聚标签 60-95% 跳变 → 锚定聚类解决。这正是元宝对话里的"地标锚定"思想（Farey 头尖 → K 线分型锚点）。
