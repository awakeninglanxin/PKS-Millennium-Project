## 一、管线通用化框架

任何自相似分形要集成到逆M渲染中，需满足以下抽象接口：

```
┌──────────────────────────────────────────────────────────────┐
│ 接口1: 离散查找表 LUT[i][j] ∈ {0, 1, ..., K-1}              │
│   生成一个 N_ROWS × N_COLS 的离散矩阵，每个元素的值为纹理索引  │
│   0 = 空白/基底, 非0 = 不同纹理类别                           │
├──────────────────────────────────────────────────────────────┤
│ 接口2: 坐标映射 f: (n,k) → (x,y) ∈ ℝ²                        │
│   将查找表索引(n,k)映射到二维平面上的一个点                    │
├──────────────────────────────────────────────────────────────┤
│ 接口3: 旋转对称群 G = {R₀, R₁, ..., R_{M-1}}                │
│   平铺时使用的旋转操作集合，M = 覆盖数                         │
├──────────────────────────────────────────────────────────────┤
│ 接口4: 像素反查 query: (x,y) → {0, 1, ..., K-1}             │
│   给定平面上一点，返回纹理索引或0(未命中)                      │
├──────────────────────────────────────────────────────────────┤
│ 接口5: fill率与维数指标                                       │
│   FillRate = P(命中) ∈ [0,1]                                 │
│   D_eff = 有效分形维数                                        │
└──────────────────────────────────────────────────────────────┘
```

## 二、候选分形家族分析

### 2.1 Sierpinski 家族（三角形/地毯/六边形）

**生成规则**：迭代删除/保留子块

| 分形 | LUT 生成 | 坐标映射 | 旋转对称 | 推荐 M | Fill 趋势 |
|------|------|------|------|------|------|
| **Sierpinski 三角** (p=2 Pascal) | Pascal mod 2 或递归分治 | 六向帕斯卡坐标 | 6 | 6 | 可调 P |
| **Sierpinski 地毯** | 3×3 网格递归（保中心的 n²−1 块） | 正方形网格坐标 | 4（或 8） | 4 | 由递归深度控制 |
| **Sierpinski 六边形** | 六边形网格递归 | 六边形坐标 | 6 | 6 | 由递归深度控制 |
| **Vicsek 分形** | 3×3 十字递归 | 正方形坐标 | 4 | 4 | 每层保留率 5/9 |

**关键参数**：
- 递归深度 `d` → N_ROWS = b^d（b 为基底边长）
- 每层保留率 `r = K_retained / K_total`
- Fill ≈ r^d × 旋转放大因子

**Sierpinski 地毯示例（4向平铺）**：
```
基底: 3×3 网格，保留角上 8 块（留中心孔）
r = 8/9
N_ROWS = 3^d = 729 (d=6)
Pascal非零率 ≈ r^d = (8/9)^6 ≈ 53.5%
有效 D = log(8)/log(3) ≈ 1.893
```

---

### 2.2 Koch 雪花家族

**生成规则**：线段→替代为 4 段折线

| 分形 | LUT 生成 | 注意事项 |
|------|------|------|
| **Koch 雪花** | 需离散化曲线为像素/网格 | 曲线是 1D 嵌入 2D，fill=0（面积为零） |
| **Koch 反雪花** | 同雪花 | 方向向内 |
| **Cesàro 分形** | 参数化角 α | α 可调 |

⚠️ **关键陷阱**：Koch 类分形是曲线（面积=0），不适合作为平面纹理（fill→0 当分辨率→∞）。**解决方案**：
1. 用有限宽度笔画渲染曲线（Koch 线的 Bresenham 离散化 + 线宽）
2. 或使用 **Koch 雪花瓷砖**（tiling），将雪花放大至填充空间
3. 将曲线段上的每个点作为一个离散单元

**Koch 雪花瓷砖方案**：
```
生成深度 d 的 Koch 雪花 → 缩放到 N_ROWS × N_ROWS 网格
每个被雪花曲线穿过的像素 → mod=1
每个雪花内部像素 → mod=2（或 0 如果只画轮廓）
旋转对称: C6（雪花正六边形对称）→ M=6
Fill ≈ (曲线总长 × 线宽) / N_ROWS²
维数 D = log(4)/log(3) ≈ 1.262（曲线本身）
平铺后有效 D 取决于线宽参数
```

---

### 2.3 龙形曲线家族

| 分形 | LUT 生成 | 坐标映射 | 旋转对称 |
|------|------|------|------|
| **Heighway 龙** | 递归 L-system，离散化到网格 | 正方形坐标 | C4（近似） |
| **Harter-Heighway 龙** | L-system | 正方形 | C4 |
| **Lévy C 曲线** | L-system | 正方形 | C2 |

⚠️ **关键陷阱**：龙形曲线是空间填充曲线——当深度→∞时 fill→100%，失去纹理结构。**解决方案**：限定递归深度，平衡细度与空白。

**龙形曲线瓷砖方案**：
```
深度 d 的龙曲线 → N = 2^d 网格
M = 4（正方形平铺，龙曲线近似填充 2^d×2^d 方块的 50%）
Fill ≈ 0.50（随 d 振荡但趋向 0.50）
D = 2（空间填充极限）
```

---

### 2.4 Apollonian 垫圈

**生成规则**：圆与圆的切圆递归

⚠️ **不推荐**：Apollonian 垫圈是圆填充，不是基于网格的离散结构，难以映射到像素坐标的 LUT。像素反查需计算到最近圆的距离→计算量大。

## 三、通用优化框架

### 3.1 Fill 率优化

**核心公式**：
$$\text{Fill}_{\text{render}} = \text{Fill}_{\text{LUT}} \times A_{\text{rotation}}$$

其中 $A_{\text{rotation}}$ 是旋转平铺的放大因子：

| 旋转对称群 | M（覆盖数） | $A_{\text{rotation}}$（经验值） |
|------|------|------|
| C2 | 2 | 1.0–1.3 |
| C3 | 3 | 1.2–1.6 |
| C4 | 4 | 1.3–1.8 |
| C6 | 6 | 1.5–2.5 |

**LUT Fill 优化策略**：

| 策略 | 机制 | 适用场景 | 效果 |
|------|------|------|------|
| **调节递归深度 d** | 深→细→fill↓, 浅→粗→fill↑ | 所有递归分形 | 主要杠杆 |
| **调节模数 P**（Pascal 特供） | P↑→Lucas 留存率↑ | Pascal 类 | 大 P = 高 fill |
| **调节基底的保留率 r** | 删子块数 / 总子块数 | 地毯/Vicsek | r↑→fill↑ |
| **调节线宽** | 曲线分形的离散化线宽 | Koch/龙形 | 线宽↑→fill↑ |
| **周期延拓** | n → n%N_ROWS，超出部分复用 | 所有 LUT 方案 | fill↑（重复采样） |
| **优先级策略** | 多方向命中取 min(n) | 所有方案 | fill↑（偏密集区） |

### 3.2 分形维数 D 优化

**通用定义**：
$$N(\epsilon) \propto \epsilon^{-D}$$

对于 LUT 方案：$N(\epsilon) = \text{不同尺度下非零格点数}$。

| 分形 | D 公式 | 控制参数 | D 范围 |
|------|------|------|------|
| Sierpinski 三角 (mod P) | $\log(P(P+1)/2)/\log(P)$ | P | [1.58, 2) |
| Sierpinski 地毯 | $\log(n^2-1)/\log(n)$ | n（基底边长） | [1.89, 2) |
| Vicsek | $\log(5)/\log(3)$ | 固定 | 1.465 |
| Koch 曲线 | $\log(4)/\log(3)$ | 固定 | 1.262 |
| Heighway 龙 | 2（极限） | 深度 d | [1, 2)，d 小则近 1 |
| Menger 海绵 (3D) | $\log(20)/\log(3)$ | 固定 | 2.727 |

**关键洞察**：Pascal mod P 是唯一可**连续调节 D** 的方案（通过 P），其他分形的 D 通常是固定值或离散阶跃。

### 3.3 视觉质量指标

| 指标 | 定义 | 最优范围 | 调整方式 |
|------|------|------|------|
| **Fill%** | 命中像素占比 | 30–70% | d, r, P, 线宽 |
| **聚类度** | 相邻像素的颜色一致性 | 中等 | LUT 结构决定 |
| **方向各向同性** | 六向覆盖的均匀性 | 高 | 旋转对称群选择 |
| **边界锐度** | LUT 中 0/1 过渡的陡峭程度 | 中等 | 线宽 vs 离散化精度 |
| **Möbius 拉伸适应** | Möbius 变换后纹理是否自然 | 自然即可 | 坐标映射中预补偿 |

## 四、通用实现步骤

### Step 1: 选择分形，生成 LUT

```python
# 通用接口
def generate_lut(N_ROWS, params) -> np.ndarray:
    """
    Returns: (N_ROWS, N_ROWS) int array
    0 = blank, non-zero = texture class
    """
    pass
```

### Step 2: 定义坐标映射 → 六向反查

对于任意 LUT，坐标映射的核心是找到 (n,k) ↔ (x,y) 的关系。

**正方形分形**（地毯/Vicsek/龙形）→ 用正方形网格坐标：
- (n,k) → (x,y) = (k, n)
- 旋转对称群 C4 → M=4，角度 0°, 90°, 180°, 270°

**三角形/六边形分形**（Sierpinski/Koch 瓷砖）→ 用六向帕斯卡坐标：
- (n,k) → (x,y)：同帕斯卡映射
- 旋转对称群 C6 → M=6

### Step 3: 像素反查

```python
def query_lut(x, y, lut, N_ROWS, periodic=True):
    """
    给定平面坐标(x,y)，返回纹理类别(0=空白, >0=纹理索引)
    """
    for m in range(M):
        xr, yr = rotate(x, y, -angles[m])
        n, k = coord_to_index(xr, yr, coord_type)
        if periodic: n = n % N_ROWS
        if 0 <= k <= n < N_ROWS and lut[n, k] > 0:
            return lut[n, k], n  # 命中
    return 0, -1  # 未命中
```

### Step 4: 集成到 Möbius 管线

```python
# Möbius 变换作用于 interior 像素
w_int = w_grid[interior]
z_mob = mobius(w_int, a, b, c, d) - center

# 像素反查
for each interior pixel:
    idx = query_lut(z.real, z.imag, lut, N_ROWS)
    if idx == 0:
        color = blank_color
    else:
        color = palette[idx]  # 按索引着色
```

## 六、快速调参表

| 目标 | 方法 | 具体操作 |
|------|------|------|
| 提高 Fill | 减小 HEX_SCALE | 更多像素命中密集行 |
| 提高 Fill | 增大 P（Pascal）或减浅 d（递归） | 留存率↑ |
| 降低 Fill | 增大 HEX_SCALE 或加深 d | 反操作 |
| 减少环状伪影 | 固定空白色（不随 n 渐变） | 仅用纹理本身变化 |
| 增强对称性 | 旋转群角度对齐主轴 | 六边形用 −30°，正方形用 0° |
| 提高渲染速度 | 减小 N_ROWS | 查找表缩小 |
| 丰富色彩 | 多 mod 值分组着色 | K 类余数各一色 |
| 避免 Möbius 拉伸失真 | 调整 center / (a,b,c,d) | 核点对齐到纹理中心 |

## 七、快速原型模板

```python
#!/usr/bin/env python
"""通用自相似分形 → 逆M渲染 快速原型"""
import numpy as np

# --- 1. 选择分形 ---
FRACTAL = 'pascal'  # 'pascal' | 'carpet' | 'vicsek' | 'koch'

# --- 2. LUT 生成 ---
def build_lut(N, fractal_type, **params):
    if fractal_type == 'pascal':
        P = params.get('P', 16)
        lut = np.zeros((N, N), dtype=np.int16)
        lut[0, 0] = 1 % P
        for n in range(1, N):
            lut[n, 0] = lut[n, n] = 1 % P
            for k in range(1, n):
                lut[n, k] = (lut[n-1, k] + lut[n-1, k-1]) % P
        return lut
    
    elif fractal_type == 'carpet':
        d = params.get('depth', 4)
        # Sierpinski 地毯: 3^d 分辨率, 递归删除中心块
        size = 3 ** d
        lut = np.ones((size, size), dtype=np.int16)
        def carve(r0, c0, sz):
            if sz < 3: return
            s = sz // 3
            lut[r0+s:r0+2*s, c0+s:c0+2*s] = 0  # 挖中心
            for i in range(3):
                for j in range(3):
                    if i != 1 or j != 1:
                        carve(r0+i*s, c0+j*s, s)
        carve(0, 0, size)
        return lut[:N, :N]  # 截取 N_ROWS
    
    elif fractal_type == 'vicsek':
        d = params.get('depth', 4)
        size = 3 ** d
        lut = np.zeros((size, size), dtype=np.int16)
        def draw(r0, c0, sz):
            if sz == 1: lut[r0, c0] = 1; return
            s = sz // 3
            draw(r0+s, c0, s); draw(r0, c0+s, s); draw(r0+2*s, c0+s, s)
            draw(r0+s, c0+s, s); draw(r0+s, c0+2*s, s)
        draw(0, 0, size)
        return lut[:N, :N]
    
    return None

# --- 3. 旋转对称 + 坐标映射 ---
def get_symmetry(fractal_type):
    if fractal_type in ('pascal',):
        M = 6
        angles = np.array([m*np.pi/3 - np.pi/6 for m in range(M)])
        coord_type = 'hex'
    elif fractal_type in ('carpet', 'vicsek'):
        M = 4
        angles = np.array([m*np.pi/2 for m in range(M)])
        coord_type = 'square'
    return M, angles, coord_type

# --- 4. 坐标到索引 ---
def coord_to_index(x, y, coord_type, N):
    if coord_type == 'hex':
        k = round(2*y/np.sqrt(3))
        n = round(x + y/np.sqrt(3))
    elif coord_type == 'square':
        n = round(y)
        k = round(x)
    return max(0, n), max(0, k)

# --- 5. 查询 ---
def query(x, y, lut, M, angles, coord_type, N, periodic=True):
    best_mod = 0; best_n = N
    for m in range(M):
        c, s = np.cos(-angles[m]), np.sin(-angles[m])
        xr, yr = x*c - y*s, x*s + y*c
        n, k = coord_to_index(xr, yr, coord_type, N)
        if periodic: n = n % N
        if 0 <= k <= n and n < N and lut[n, k] > 0:
            if n < best_n:
                best_mod = lut[n, k]; best_n = n
    return best_mod, best_n
```

此模板可直接替换当前的 `hex_pascal_mod` 函数，将分形选择参数化。
