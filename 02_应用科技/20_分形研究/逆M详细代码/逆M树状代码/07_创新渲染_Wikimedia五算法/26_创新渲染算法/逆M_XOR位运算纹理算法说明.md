## 一、原始算法原理

XOR 纹理算法的核心思想是使用位异或运算生成重复的周期性图案：

```
原始纹理 = f(i, j) = i XOR j
```

其中 i、j 是像素的整数坐标。这个简单的运算会产生棋盘状的重复图案，通过调整位移量可以得到不同粗细的纹理。

---

## 二、逆M适配思路

**关键改进**：从使用全局像素坐标改为使用**逆M迭代数据驱动**。这样纹理就"长"在逆M水滴的形状内，而非覆盖整个画布。

### 2.1 逆M迭代数据的选用

- **逃逸迭代数 (ic)**: 决定每个像素的"深浅"，是异或运算的主要数据来源
- **反演复数 (co)**: 像素在反演空间的位置，可用作辅助坐标

### 2.2 数据映射

```python
# 原始坐标 → 逆M数据驱动
# 旧版（错误）: 用全局像素坐标 (ii, jj) 做 XOR → 与水滴无关
# 新版（正确）: 用逆M逃逸迭代数 ic 做 XOR → 纹理依附于水滴形状
```

## 三、算法实现流程

### 3.1 迭代引擎

使用标准逆M迭代公式：
$$z_{n+1} = z_n^2 + c_{\text{eff}}, \quad c_{\text{eff}} = \frac{1}{c}$$

- 当 |z|² > BAILOUT_SQ 时，记录逃逸迭代次数 `ic`
- 未逃逸的点属于 interior（水滴内部区域）

### 3.2 XOR 纹理生成

```python
def render_xor(ic, co, w, h, interior):
    # 只在 interior 区域处理
    ic_int = (ic[interior] / MAX_ITER * 127).astype(np.int32)
    
    # 高低位分离做XOR
    hi = (ic_int >> 4) & 0xF    # 高4位
    lo = ic_int & 0xF          # 低4位
    xor_val = (hi ^ lo).astype(np.float64) / 15.0  # [0, 1]
    
    # HSV色彩映射
    hue = xor_val * 6
    sat = 0.7 + 0.3 * xor_val
    val = 0.2 + 0.8 * xor_val
    rgb = hsv_to_rgb(hue, sat, val)
    
    # 设置图像 + 黑底 + 旋转
    img[interior] = rgb
    img[~interior] = 0           # exterior 黑底
    return np.rot90(img, k=2)   # 180°旋转，水滴朝上
```

### 3.3 色彩映射

将 XOR 值 [0,1] 映射到 HSV 空间：

| 参数 | 公式 | 说明 |
|------|------|------|
| Hue | `xor_val * 6` | 在色相环上循环 |
| Saturation | `0.7 + 0.3 * xor_val` | 随亮度增加饱和度 |
| Value | `0.2 + 0.8 * xor_val` | 随亮度增加亮度 |

## 四、关键技术要点

### 4.1 数据驱动纹理 ✓

- **不使用全局像素坐标**，只用逆M的 `ic` 值
- 纹理随水滴形状变化，内部细节丰富
- exterior 区域留纯黑，突出水滴主体

### 4.2 等轴比视图 ✓

- 使用 `RES×RES` 正方形数组
- RE轴和IM轴物理尺度相等（通过统一跨度实现）
- `np.rot90(img, k=2)` 旋转使水滴尖朝上

### 4.3 位运算细节

- 将迭代数缩放到 0-127 范围
- 高4位和低4位做XOR，产生15种变化
- 比简单的 `ic >> 4` 产生更丰富的纹理

## 五、参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| MAX_ITER | 250 | 最大迭代次数 |
| BAILOUT_SQ | 256² | 逃逸阈值平方 |
| ic缩放 | /MAX_ITER * 127 | 映射到7位 |
| 位操作 | (ic>>4) & 0xF | 取高4位 |
| XOR范围 | 0-15 | 15种色相变化 |
| 旋转 | np.rot90(k=2) | 水滴朝上 |
