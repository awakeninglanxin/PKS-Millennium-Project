## 一、最终算法公式链

### 1.1 坐标系统（复平面 → 像素）

```
C = Y + j·X
X ∈ [-4.0, 4.0]    虚数轴(水平)
Y ∈ [-2.5, 5.5]    实数轴(垂直, 上下翻转使实轴朝下)
RES = 1200×1200
```

### 1.2 迭代引擎

```
α = -1.0                    (逆M模式, s=1)
ce = c^α = 1/c              (复反演, 合并到幂运算)

z₀ = 0
z_{n+1} = z_n² + ce         (标准Mandelbrot迭代)
bailout: |z|² > 1024       (R² = 32²)
max_iter: 400
```

### 1.3 输出数据

| 变量 | 含义 |
|------|------|
| `ic` | 逃逸迭代次数 (0~400, 400=未逃逸) |
| `trap` | 轨道陷阱 = 迭代过程中 |z|² 的最小值 |
| `Zr, Zi` | 最终 z 值 (逃逸时的值 / 第400轮的值) |

### 1.4 着色公式

**内部**（`ic ≥ 400` = 水滴区域）：
```
v_int    = 4 × ln(trap + 1e-9)
v_arr    = 0.3 + 0.7 × v_int
```

**外部**（`ic < 400` = 逃逸区域）：
```
nu       = 1 / |z|                              ( |z| 的倒数 )
v_smooth = (ic + 1 - nu) × 0.1                  (平滑连续势能)
v_arr    = v_smooth                              (直接用作颜色值)
```

### 1.5 调色板（LUT）

```
3段渐变, 256色:
  深蓝 ([5,10,50])
→ 蓝白 ([220,230,245])
→ 金色 ([255,180,60])
→ 深棕 ([120,55,8])

映射: vi = (v_arr × 255) % 256  → LUT[vi]
```

### 1.6 图像朝向

```
img = img[::-1, :, :]   # 上下翻转 → 实数轴朝下(水滴尖朝上)
```

## 二、关键设计决策

### 2.1 向外辐射方向

```diff
- 使用 arg(C) 从全局原点算角度         → False
- 使用 arg(C - 水滴中心) 从质心算角度   → False
+ 使用 -∇ic (梯度反方向) 做向外方向    → True
```

梯度 `∇ic = (∂ic/∂x, ∂ic/∂y)` 指向 ic 增加方向（= 指向水滴内部），取反 = 指向水滴外部。

### 2.2 外部平滑公式

```diff
- nu = log₂(log₂(|z|²)/2/ln2)/ln2     → 复杂, 原始DNA代码
+ nu = 1/|z|                           → 简化
```

```diff
- v_smooth = (ic+1-nu) × 0.1  % 1     → 取余循环
+ v_smooth = (ic+1-nu) × 0.1           → 直接使用, 靠LUT索引自然循环
```

### 2.3 内部公式

```diff
- v_int = ln(trap) × 0.55  % 1          → 原始DNA代码
+ v_int = 4 × ln(trap)                  → 当前版本
```

### 2.4 二分棋盘（已取消）

```
16射线梯度方向 → 射线奇偶 ⊻ 迭代奇偶 → XAND棋盘
当前状态: 已取消, 仅保留纯平滑着色
```

## 四、当前效果特征

- **水滴内部**：`4×ln(trap)` 产生对数间距的同心圆纹，随 `v_arr × 255 % 256` 在LUT中自然循环
- **水滴外部**：`(i+1-1/|z|)×0.1` 产生平滑连续势能色带，大值靠LUT索引 `%256` 产生多次循环
- **颜色过渡**：深蓝→蓝白→金→棕，3段渐变
- **水滴朝向**：实轴朝下（上下翻转）
- **视窗**：[-4,4] × [-2.5,5.5]，等轴比
