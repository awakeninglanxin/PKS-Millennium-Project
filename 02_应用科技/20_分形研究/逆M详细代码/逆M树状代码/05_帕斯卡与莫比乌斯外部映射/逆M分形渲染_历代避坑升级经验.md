## 二、🔴 踩坑记录 (按严重程度)

### 🚨 坑1: interior/escaped 搞反 (最严重, 犯过2次)

**症状**: 帕斯卡纹理跑到水滴外面, 水滴内部却是纯色

**根因**: 逆M中 `interior=未逃逸=水滴内部`; 用户画的是**逆M不是正M**

**铁律**: 
```
interior = 未逃逸 = 水滴内部 = 帕斯卡纹理
escaped  = 逃逸   = 水滴外部 = 纯色背景
```

### 🚨 坑2: 曲线分形直接当 LUT 用 → fill≈0

**症状**: Lévy 龙形深度12+线宽8px, LUT fill 仍只有 2-12%

**根因**: 曲线是 1D 嵌入 2D, 面积趋近 0

**解决方案** (三选一):
1. **洪水填充**: Koch-8 曲线闭合cell → 交替填充 → 51.9%
2. **多副本**: 8条龙从四边出发 → 12.5%
3. **粗线**: 线宽3px以上 (但细节丢失)

### 🚨 坑3: HEX_SCALE 固定缩放无法覆盖 Möbius 小坐标

**症状**: Möbius zmv 范围 re[0.1,2.8] im[-2.5,2.5], HEX_SCALE 缩放后只覆盖 LUT 30-50%

**根因**: 归一化缺失, 坐标映射不到 LUT 全域

**解决方案**: 归一化映射
```python
nr = (zi - zi_min) / (zi_max - zi_min) × (N_ROWS-1)
```
→ Lévy Tapestry fill 从 0.7% → 75.7% 🚀

### 🚨 坑4: 8龙 LUT 曲线局部化 → Möbius+HEX_SCALE 全 0%

**症状**: 4个 HEX_SCALE 全部 fill=0%

**根因**: 曲线包围盒 [542,1505], 而坐标映射落在包围盒外

**解决方案**: **必须 +N_ROWS/2 中心偏移**
```python
nr = round(zi/HEX_SCALE) + N_ROWS//2   # zmv中心→LUT中心
```
→ fill 0% → 67.3% 🚀

**关键差异**: Pascal LUT 全域有值(不需偏移), 8龙 LUT 局部有值(必须偏移)

### 🚨 坑5: 源图与渲染参数不一致 (用户发现)

**症状**: 用户说"没有基于8龙源图生成, 只有4条龙"

**根因**: 调 fill 时把 S 从 10 改成 6, 忘了源图是 S=10

**铁律**: 渲染脚本参数必须与源图生成脚本**逐字节一致** (DEPTH/S/线宽/configs)

### 🚨 坑6: HEX_SCALE 对 fill 非单调

**症状**: 0.003→67%, 0.005→87%, 0.007→77%, 0.01→68%

**根因**: 映射区域与曲线包围盒是几何交叠, 非线性

**铁律**: 调 HEX_SCALE 必须实测扫描, 不能假设单调

### 🚨 坑7: Python 变量遮蔽 bug

**症状**: `TypeError: unsupported operand type(s) for -: 'tuple' and 'int'`

**根因**: 递归函数参数 `d`(深度) 和局部点 `d=(x,y)` 同名

**铁律**: 递归深度参数用 `depth/dp`, 避免与坐标点变量名冲突

### 🚨 坑8: 旧文件覆盖导致版本混乱

**症状**: 用户看到的 D14 图还是旧 4 龙版本

**根因**: 改造 8 龙后只跑了 D13, D14 文件未重新生成

**铁律**: 参数改造后**所有**深度版本都要重跑, 检查文件时间戳

### ⚠️ 坑9: 洪水填充 O(N²) 太慢

**症状**: Koch-8 LUT 洪水填充 2048² 需 230s

**解决方案**: stride=2 步进扫描 (准确度损失可忽略) → 10-13s

### ⚠️ 坑10: 线宽对 fill 的放大效应

**症状**: 3px 线 → fill 87%, 1px 线 → fill 68%

**铁律**: 线宽是 fill 的离散粗调旋钮 (3px→1px = ÷2.5)

## 三、🏆 成功经验 (可复用模式)

### 模式1: 归一化映射 (核心创新)

```python
# 任何 LUT 反查的第一步: 把坐标映射到 LUT 全域
nr = (coord - min) / (max - min) * N_ROWS
# 或: coord/HEX_SCALE + 中心偏移
```

### 模式2: 曲线分形→纹理 三步法

```
① 多副本平铺 (四边×正反双旋=8)  → 覆盖整个LUT
② 线宽控制 fill (1px 疏, 3px 密)
③ 洪水填充 (仅当曲线自闭合, 如Koch-8)
```

### 模式3: 核点对齐

```python
# 中心对齐 w=0
zmv = f(w) - f(w=0)   # Möbius方案
zmv = 1/w              # 倒数方案
# 中心对齐 1/w=0 (w→∞)
zmv = f(w) - 1         # Möbius方案 (f(∞)=1)
```

### 模式4: 多路查询放大 fill

```python
# fill ≈ 1 - (1 - LUT_fill×覆盖)^M
M=1 → fill≈LUT fill (太低)
M=2 → ×2 命中
M=4 → ×4 命中
# 8龙LUT自带对称, M=2 最平衡
```

### 模式5: 金白cmap 双端渐变

```python
color = GOLD×(1-t) + WHITE×t   # t=n/N_ROWS
# 中心(n小)金 → 边缘(n大)白
```
