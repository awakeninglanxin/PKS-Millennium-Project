## 二、各阶段详细

### 2.1 LUT 生成 (Lévy 4-dragon)

**L-system**:
```
Axiom: F
Rule:  F → +F--F+
Angle: 45° (8方向)
```

**四条龙分别从正方形四角出发**:
```
起始点     起始方向    色码  颜色
(-10,-10)   45° (NE)    1    蓝
( 10,-10)  135° (NW)    2    绿
( 10, 10)  225° (SW)    3    红
(-10, 10)  315° (SE)    4    橙
```

每条龙经过 13 次 L-system 展开 → 2^13 = 8192 个 turtle 步 → 约 8192 像素路径。四条龙的坐标拼接后统一缩放到 2048×2048 网格。

**关键**: 没有洪水填充——纯曲线自身纹理。线宽 5px（±2 范围）。

### 2.2 逆Mandelbrot 迭代

视窗: 水滴边界精确值外扩+4：
- Re ∈ [-5.333, 8.0]
- Im ∈ [-5.624, 5.624]

```
c_eff = 1/w
z_{n+1} = z_n² + c_eff
逃逸半径: 50
最大迭代: 300
```

`interior` = 迭代到 300 步仍未逃逸的点 = 水滴内部像素。

### 2.3 Möbius 共形映射

$$f_M(w) = \frac{w}{w-2}$$

**中心对齐到核点**: `1/w = 0` 对应 `w → ∞`, `f_M(∞) = 1`。

```python
zm = f_M(w_int)      # 原始 Möbius 坐标
zmv = zm - 1.0       # 中心化: zmv=0 对应核点
```

核点 zmv=0 经归一化后映射到 LUT 中心 (N_ROWS/2, N_ROWS/2)。

| 极点位置 | 核点位置 | 水滴尖 | 水滴底 |
|------|------|------|------|
| w=2 (Möbius极点) | w=∞ (核点) | w=4 (尖) | w=-4/3 (底) |
| f(w)→∞ | f(w)=1 | f(4)=2 | f(-4/3)=0.5 |

### 2.4 归一化坐标映射

这是让 C4 正方形坐标正确覆盖 LUT 的**关键创新**:

```python
zr_min, zr_max = zmv.real.min(), zmv.real.max()
zi_min, zi_max = zmv.imag.min(), zmv.imag.max()
nr = (zi - zi_min) / (zi_max - zi_min) * (N_ROWS - 1)  # → [0, N_ROWS)
kr = (zr - zr_min) / (zr_max - zr_min) * (N_ROWS - 1)  # → [0, N_ROWS)
```

**为什么不用 HEX_SCALE**: Möbius 坐标范围太小（~[-1,2]×[-2.5,2.5]），固定 HEX_SCALE 无法覆盖完整 LUT。归一化确保每个 zmv 值都能映射到 LUT 的每个格子。

### 2.5 C4 旋转反查

```python
for m in 0..3:  # 0°, 90°, 180°, 270°
    z_rotated = zmv * e^(-imπ/2)    # 反旋转
    (nr, kr) = normalized_map(z_rotated)
    ne = nr % N_ROWS; ke = kr % N_ROWS
    if LUT[ne, ke] > 0:
        record (mod, n)  # 取 n 最小的
```

C4 旋转群对应正方形平铺。每个 interior 像素有 4 次机会命中 LUT。

## 三、可调参数表

### 3.1 LUT 参数

| 参数 | 当前值 | 作用 | 调大效果 |
|------|------|------|------|
| **DEPTH** | 13 | L-system 展开次数 | 段数×2 → 更密更细 → fill↑ |
| **S** | 10 | 正方形半边长 | 四条龙起点间距↑ → 覆盖面积↑ → fill↑ |
| **线宽** | 5 (range±2) | 曲线宽度 | fill↑, 但细节丢失 |
| **N_ROWS** | 2048 | LUT分辨率 | 更高分辨率 → 更细 → fill↓ |
| **sc** | 0.47 | 曲线缩放 (0.47=占画布47%) | fill↑ |

### 3.2 Möbius 参数

| 参数 | 当前值 | 作用 |
|------|------|------|
| **(a,b,c,d)** | (1,0,1,-2) | f(w)=(aw+b)/(cw+d) |
| **centering** | zm-1 | 核点对齐点 (1/w=0) |
| **极点位置** | w=2 → f→∞ | 决定了拉伸程度 |

### 3.3 查询参数

| 参数 | 当前值 | 作用 |
|------|------|------|
| **M** | 4 | C4 旋转向数 |
| **归一化方式** | min/max拉伸 | 全覆盖 | 
| **优先级** | min(n) | 靠近核点的命中优先 |

### 3.4 视觉参数

| 参数 | 当前值 | 作用 |
|------|------|------|
| COLORS[1-4] | 蓝/绿/红/橙 | 四条龙的颜色 |
| bright formula | 0.6+0.4×(1-n/2048) | n值调亮度 |
| blank color | [0.30,0.20,0.08] | 暗琥珀空白色 |

## 四、Fill 率调控公式

$$\text{Fill}_{render} \approx 1 - (1 - \text{Fill}_{LUT} \times f_{cover})^M$$

其中:
- Fill_LUT = LUT 中非零像素占比 (当前 9.7%)
- f_cover = 归一化映射的有效覆盖率 (≈1.0)
- M = C4 旋转向数 = 4

$$\text{Fill}_{render} \approx 1 - (1-0.097)^4 \approx 33\%$$

实际 81% 远高于此预测 → 说明"取 n 最小"的优先级策略大幅放大了 fill。

**降低 fill 的方法**:
1. 减小 line_width → Fill_LUT↓
2. 增大 S → 四条龙间距↑, 曲线变稀
3. 减小 DEPTH → 段数减半, 曲线变稀
4. 对归一化坐标加缩放因子 (zoom out) → f_cover↓

**提高 fill 的方法**: 反操作。
