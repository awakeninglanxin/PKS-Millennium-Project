## 二、参数详解

### 2.1 DEPTH — 龙形细化程度 ⭐⭐⭐

```
段数 = 2^DEPTH
DEPTH=13 → 8192 段/条
DEPTH=14 → 16384 段/条
DEPTH=15 → 32768 段/条
```

| 效果 | 说明 |
|------|------|
| **维数 D** | 不变！Lévy 龙 D=2 固定（空间填充极限） |
| **fill%** | ↑ 缓慢上升 (段多→覆盖密) |
| **纹理细度** | ↑ 线段更短更细 (视觉更密) |
| **生成耗时** | ×2 每加 1 (字符串重写指数增长) |

**实测**: D13→fill 12.5%→D14→12.5% (LUT 层面几乎不变, 因为 N_ROWS 分辨率限制)

⚠️ **上限**: DEPTH>15 时字符串长度 2^15×5 字符 ≈ 163K 字符, 展开慢且线段短于 1 像素, 无意义

### 2.2 HEX_SCALE — fill 主控旋钮 ⭐⭐⭐

```
nr = round(zi/HEX_SCALE) + N_ROWS/2
kr = round(zr/HEX_SCALE) + N_ROWS/2
```

**映射逻辑**: HEX_SCALE↑ → nr/kr↓ → 映射区域向 LUT 中心收缩 → 与曲线包围盒[542,1505]的交叠变化

| HEX_SCALE | 粗线fill | 细线fill | 视觉 |
|------|------|------|------|
| 0.003 | 67.3% | 49.8% | 稀疏优雅 |
| 0.005 | 86.9% | **67.8%** | 平衡 |
| 0.007 | 77.2% | 55.4% | 中密 |
| 0.01 | 67.9% | 47.4% | 疏松 |

⚠️ **非单调性**: fill 不随 HEX_SCALE 线性变化, 因为映射区域与曲线包围盒是几何交叠关系。调参需实测。

### 2.3 线宽 — 粗细 ⭐⭐

```
粗线: ±1 循环 → 3×3 = 9像素
细线: 单像素 → 1像素
```

| 效果 | 说明 |
|------|------|
| fill% | 粗线≈细线×2.5 (3px vs 1px 面积比) |
| 维数 D | 不变 |
| 视觉 | 粗线→块状, 细线→蛛丝 |
| LUT fill | 12.5% (粗) → ~5% (细) |

### 2.4 S — 起始正方形半边长 ⭐

```
S=10 → 四边中点 (±10,0),(0,±10)
```

| 效果 | 说明 |
|------|------|
| fill% | S↑ → 曲线覆盖更大区域 → fill 略↑ |
| 对称性 | 不变 (仍是八边形) |
| 与包围盒 | S 决定曲线包围盒大小 |

⚠️ S 太小 (<5) 龙互相重叠; S 太大 (>15) 曲线超出画布

### 2.5 M — 旋转向数 ⭐

```
M=1: 无旋转 → fill≈LUT fill (过低)
M=2: 0°+90° → 当前
M=4: 0°+90°+180°+270° → fill↑ 显著
```

| 效果 | 说明 |
|------|------|
| fill% | M↑ → 命中机会↑ → fill↑ (几何级) |
| 耗时 | M↑ → 查询×M (线性) |
| 对称 | M=4 时四重对称更明显 |

⚠️ 8龙 LUT 本身已含 ± 镜像对称, M=4 时 fill 可能过高 (>85%)

### 2.6 中心偏移 +N_ROWS/2 ⚠️ 必调

```
曲线包围盒: x[542,1505] y[542,1505], 中心(1024,1024)
```

- **必须加** `+N_ROWS/2`: 让 zmv 中心映射到 LUT 曲线中心
- 不加 → fill=0% (坐标落在包围盒外)
- 加错中心 (如 +300) → 只命中部分曲线 → fill 低

### 2.7 sc — 曲线缩放系数

```
sc = N_ROWS × 0.47 / 路径跨度
```

| 效果 | 说明 |
|------|------|
| fill% | sc↑ → 曲线更大 → fill↑ |
| 建议 | 0.40-0.50 (0.47 当前, 留边距防溢出) |

## 三、维数 D 的控制

**Lévy 龙 D=2 固定** — 无法通过上述参数改变维数。

| 想达到的 D | 方案 |
|------|------|
| D=2.0 | Lévy 龙 (当前) — 空间填充 |
| D=1.585 | 莱维钻石 / Sierpinski 三角 |
| D=1.5 | Koch-8段 (有理数!) |
| D=1.772 | Pascal mod 16 |
| D 连续可调 | Pascal mod P (P 任意) |
| D 准连续 | Koch N→M段 log(M)/log(N) |

⚠️ 若需要**改变维数**, 必须换分形类型 (见 `帕斯卡vsLévy_共形映射对比.md`)

## 六、调参流程建议

```
1. 固定 DEPTH=14, S=10, 线宽=1px, M=2
2. 粗扫 HEX_SCALE: [0.003, 0.005, 0.007, 0.01] → 找 fill 峰值
3. 在峰值附近细扫 (±0.001) → 精确定位目标 fill
4. 若 fill 仍需大幅调整 → 换线宽 (离散跳变)
5. 最后微调 S/sc 微调覆盖范围
```

⚠️ 每次改参数只改**一个**变量, 记录 fill%, 避免多重耦合。
