## 一、数学定义

### 1.1 莱维C形曲线生成规则

初始: 一条线段。每次迭代用等腰直角三角形的两条直角边代替斜边，**两条直角边均朝外**。

```
迭代0: ———— (1条线段)
迭代1: └┘    (2段, 直角向外)
迭代2: 4段折线
...
迭代n: 2^n 段, 每段长度 = L₀ / (√2)^n
```

与普通龙形曲线的区别：普通龙形一条直角边朝外、一条朝内（左右交替），莱维龙形两条都朝外。

### 1.2 分形属性

| 属性 | 值 |
|------|------|
| 自相似部分数 | 2 |
| 缩放比 | 1/√2 ≈ 0.707 |
| 分形维数 D | log(2)/log(√2) = **2** |
| 迭代n次段数 | 2^n |
| 曲线总长 | L₀ × (√2)^n → ∞ |

虽然 D=2（空间填充级别），但莱维C形曲线**并未完全填满平面**——内部有空隙。这恰恰使其适合作为纹理。

### 1.3 4拼花毯

将4条莱维C形曲线旋转拼接（图6.4.6~7）：
- 每条曲线旋转 0°, 90°, 180°, 270°
- 4条曲线中心汇聚，形成封闭的"花毯"图案
- 整体近似填满一个正方形区域
- **C4 旋转对称**——天然适配正方形平铺

```python
def levy_dragon_segments(depth):
    """L-system 生成莱维C形曲线线段"""
    # L-system: 初始 F, 规则 F → +F--F+
    # 角度: 45°
    # + = 左转45°, - = 右转45°
    # 最终得到2^depth个线段
    
    # 简化: 用迭代坐标法
    import numpy as np
    dirs = [(1,0), (0,1), (-1,0), (0,-1)]  # 0=右,1=上,2=左,3=下
    x, y = 0, 0
    points = [(x, y)]
    angle = 0  # 起始方向
    
    # 莱维龙形的转折序列 (由折纸法生成)
    # 每次迭代: 旧序列 → 旧序列 + 左转 + 旧序列反转
    turns = []  # +1=左转, -1=右转
    for _ in range(depth):
        turns = turns + [1] + [-t for t in reversed(turns)]
    
    for t in turns:
        angle = (angle + t) % 4
        x += dirs[angle][0]
        y += dirs[angle][1]
        points.append((x, y))
    
    return np.array(points)
```

### 2.2 坐标映射

莱维4拼花毯是**正方形**填充 → 使用**正方形坐标** + **C4 旋转群**：

```python

M = 4
angles = np.array([0, np.pi/2, np.pi, 3*np.pi/2])

def square_coord_to_index(x, y, N_ROWS):
    """正方形LUT: 直接像素映射"""
    n = round(y * N_ROWS)  # 行
    k = round(x * N_ROWS)  # 列
    n = n % N_ROWS  # 周期延拓
    if 0 <= k < N_ROWS and 0 <= n < N_ROWS:
        return n, k
    return -1, -1

def query_levy(x, y, lut, N_ROWS):
    """像素反查: C4旋转 → 正方形坐标 → 查表"""
    best_mod = 0; best_n = N_ROWS
    for m in range(4):
        angle = m * np.pi / 2
        c, s = np.cos(-angle), np.sin(-angle)
        xr, yr = x*c - y*s, x*s + y*c
        n, k = square_coord_to_index(xr, yr, N_ROWS)
        if n >= 0 and lut[n, k] > 0:
            # 取离中心最近的命中 (n最小)
            dist = n  # 简化用n做优先级
            if dist < best_n:
                best_mod = lut[n, k]; best_n = dist
    return best_mod, best_n
```

### 2.3 参数调优

### 2.4 Fill 率估算

```
不填充内部:
  fill = (曲线总像素数) / N_ROWS²
  ≈ (2^depth × 线宽 × 平均段长) / N_ROWS²
  ≈ 深度12时 ~ 5-15%

填充内部 (推荐):
  fill ≈ 曲线包围面积 / 总面积 × M覆盖
  ≈ 0.50 × 1.5 ≈ 75%  (4拼花毯约填50%面积, C4覆盖1.5×)
```
