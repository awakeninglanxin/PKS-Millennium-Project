# 帕斯卡三角 vs Lévy 8龙 — 共形映射方案对比

> 对比对象:
> - **Pascal**: `逆M杨辉三角图像映射/main_hex_pascal_mobius_v10.py` → v14
> - **Lévy**: `分形图像+共形映射/run_levy_4color_v16.py` → D14

---

## 一、核心差异速览

| 维度 | 帕斯卡三角 (Pascal) | Lévy 8龙 |
|------|------|------|
| **LUT生成** | 递推 `C(n,k)≡C(n-1,k)+C(n-1,k-1) mod P` | L-system `F→+F--F+` 重写 → turtle路径栅格化 |
| **LUT数学本质** | 离散余数分布 (mod 16) | 曲线像素 (8条龙) |
| **分形维数** | D=1.772 = log(16·17/2)/log(16) | D=2.0 (空间填充极限) |
| **对称群** | C6 (六角, -30°起步) | C4×± = 8向 (八边形) |
| **坐标映射** | Möbius f=w/(w-2), 固定 HEX_SCALE | f=±1/w, 归一化映射 |
| **查询约束** | k≤n 三角区域, 周期延拓 | 正方形全尺寸, mod |
| **LUT fill** | 22.0% | 12.5% |
| **渲染 fill** | 63% | 26.3% |
| **着色** | n彩虹 (hue循环) | 金白cmap (中心金→边缘白) |
| **耗时** | ~115s | ~42s |

## 二、相同之处 (共享管线)

### 2.1 逆M迭代框架 (完全一致)

```python
c_eff = 1/w
z_{n+1} = z_n² + c_eff
逃逸半径 BL=50, 最大迭代 MI=300
interior = 未逃逸 = 水滴内部 (93.2%画面)
```

### 2.2 视窗与边界 (完全一致)

来自 `逆M水滴边框精确求解.md`:
- Re ∈ [-5.333, 8.0] (底部-4/3, 尖端+4, 外扩+4)
- Im ∈ [-5.624, 5.624] (±1.6242719, 外扩+4)
- W×H = 2400×2025

### 2.3 核点对齐 (一致, 都是 w=0)

| 方案 | 对齐方式 | 说明 |
|------|------|------|
| Pascal | `zmv = f(w) - f(w=0)` = `zm - 0` | Möbius 后减中心 |
| Lévy | `zmv = 1/w` (f(w=0)=∞ 天然在LUT外) | 直接取倒数 |

### 2.4 着色分区 (一致)

```
Interior = 帕斯卡纹理填充区
Escaped  = 纯天蓝 [0.45,0.75,0.92]
空白     = 暗琥珀 [0.30,0.20,0.08]
```

### 2.5 输出管线 (一致)

```
np.transpose(img,(1,0,2)) + origin='lower'
+ cardioid 金色轮廓线 (droplet_invM_analytic.csv)
+ 金色画框 #D4A017, 无坐标轴
```

### 2.6 LUT查询框架 (同构)

两者都是"旋转群反查 + 取 n 最小优先级":
```python
for m in range(M):          # 旋转角
    反旋转 → 坐标→(nr,kr) → mod LUT
    命中且 n 更小 → 记录
```

## 三、不同之处 (核心差异)

### 3.1 LUT 生成机制

**Pascal — 离散递推**:
```python
pascal[n,0] = pascal[n,n] = 1 % P
pascal[n,k] = (pascal[n-1,k] + pascal[n-1,k-1]) % P
```
- 复杂度 O(N²) 递推
- 数学依据: Lucas定理 `C(n,k) mod P ≠ 0 ⇔ k_P ≤ n_P`
- fill = 2×((P+1)/(2P))^m 可解析预测

**Lévy — 字符串重写**:
```python
Rule: F → +F--F+   (2^depth 次重写)
turtle 走步 → 路径点 → Bresenham 栅格化
```
- 复杂度 O(2^depth) 指数
- 数学依据: 折纸折叠的自相似序列
- 8条龙 = 4起点 × (正旋/反旋镜像)

### 3.2 对称群

**Pascal — C6 六角**:
```
角度: -30°, 30°, 90°, 150°, 210°, 270°  (六边形边对齐实轴)
查询约束: 0 ≤ k ≤ n  (三角形区域)
```
- 天然匹配六角平铺
- k≤n 约束使查询区域减半

**Lévy — C4×± 八边形**:
```
旋转: 0°, 90°, 180°, 270°
镜像: ± 双分支
= 8 路查询
查询约束: 无 (正方形全尺寸)
```

### 3.3 坐标映射

**Pascal — Möbius + 固定缩放**:
```python
zmv = w/(w-2) - 0        # f(w)=w/(w-2)
nr  = round(zi/HEX_SCALE)   # HEX_SCALE=0.003 固定
kr  = round(zr/HEX_SCALE)
```
- 极点 w=2 产生方向性拉伸
- HEX_SCALE 需手动调 (0.003 → fill 63%)

**Lévy — 倒数 + 归一化**:
```python
zmv = 1/w                 # f=±1/w 双分支
nr  = (zi-zi_min)/(zi_max-zi_min)×2047   # 归一化
kr  = (zr-zr_min)/(zr_max-zr_min)×2047
```
- 1/w 天然匹配逆M本质
- 归一化自动全覆盖 LUT (无手动缩放)

### 3.4 着色方案

**Pascal — n彩虹**:
```python
hue = 0.12 - n/2048×0.65    # 红→橙→黄→绿→蓝→紫
sat = 0.7 + 0.3×n/2048
val = 0.5 + 0.5×(1-n/2048)
```
- n 值 = 帕斯卡行号 → 每圈等距线同色
- 视觉: 同心彩虹环 + 三角孔洞纹理

**Lévy — 金白cmap**:
```python
color = GOLD×(1-t) + WHITE×t   # t=n/2048
GOLD=[0.95,0.72,0.10], WHITE=[1,1,1]
```
- 8龙无差别, 单色渐变
- 视觉: 中心金 → 边缘白, 8龙缠绕纹理

### 3.5 fill 调控杠杆

| 杠杆 | Pascal | Lévy |
|------|------|------|
| 主参数 | **P (模数)** → D 连续可调 | **depth** → 段数×2 |
| 次参数 | HEX_SCALE | S (起点距), 线宽, M |
| 填充率公式 | 2×((P+1)/(2P))^m 解析 | 经验 (约 12%×覆盖) |
| 典型 fill | 63% (P=16) | 26.3% (D14) |

## 四、数学本质对比

### Pascal: 余数代数结构
$$C(n,k) \bmod P \neq 0 \iff k_P \le n_P$$
- 三角网格上的离散代数
- 纹理 = 余数的分布 (mod 16 的 16 类)
- 分形维数可解析: $D(P) = \frac{\log(P(P+1)/2)}{\log P}$

### Lévy: 迭代函数系统 (IFS)
$$\text{替换: } \frac{1}{\sqrt{2}}R_{\pm45°} \text{ 应用于每段}$$
- 折纸折叠的极限
- 纹理 = 曲线的像素轨迹
- D=2 固定 (空间填充)

## 五、适用场景建议

| 场景 | 推荐 | 理由 |
|------|------|------|
| 需要可调分形维数 | **Pascal** | D(P) 随 P 连续变化 |
| 需要 60%+ 填充率 | **Pascal** | fill 稳定 63% |
| 需要八边形对称 | **Lévy** | C4×± 天然八边形 |
| 需要稀疏优雅纹理 | **Lévy** | fill 26.3% 疏朗 |
| 需要金白单色渐变 | **Lévy** | 金白cmap |
| 渲染速度快 | **Lévy** | 42s vs 115s |
| 需要彩虹环效果 | **Pascal** | n彩虹 |

## 六、结论

1. **共享 70% 管线**: 逆M迭代/视窗/核点/着色分区/输出框架完全一致
2. **核心差异在 LUT**: Pascal 是代数递推 (余数), Lévy 是几何重写 (曲线)
3. **对称群决定查询**: C6 六角 vs C4×± 八边形 → 不同坐标约束
4. **映射与缩放**: Möbius+HEX_SCALE vs 倒数+归一化 (后者免调参)
5. **fill 杠杆不同**: P 连续调节 vs depth/线宽离散调节
6. 两者可共存: 一套逆M管线, 两个 LUT 插槽, 按需切换
