## 算法一: 平滑逃逸时间 (Smooth Escape Time)

### 公式

$$\mu = n + 1 - \frac{\log(\log |z_n|)}{\log d}$$

其中 $n$ = 离散逃逸步数，$d$ = 映射次数 (z²→d=2)。

### 数学来源

源自势函数理论: $\phi(c) = \lim_{n\to\infty} \frac{\log |z_n|}{2^n}$。$\mu$ 是势函数在离散网格上的连续插值。

### Python 核心代码

```python
for n in range(max_iter):
    z = z*z + 1/c
    if abs(z) > BAILOUT:
        mu = n + 1 - np.log(np.log(abs(z))) / np.log(2)
        color = palette(mu / max_iter)
        break
```

### 适用逆M的原因

逆M水滴外部对应标准M内部——原本"全黑无信息"的区域变成了缓慢逃逸区。$\mu$ 从边界向外形成连续梯度。

## 算法二: 轨道陷阱 (Orbit Trap)

### 原理

不再问"什么时候逃逸"，而是追踪整条轨迹 $\{z_0, z_1, z_2, ...\}$ 到某形状的最小距离:

$$d_{\min} = \min_{0 \le n < N} \text{dist}(z_n, \text{trap})$$

### 常见陷阱

| 陷阱 | 距离公式 | 效果 |
|:---|:---|:---|
| 点陷阱 (原点) | $\min |z_n|$ | 放射状丝线 |
| 线陷阱 (实轴) | $\min |\text{Im}(z_n)|$ | 水平条纹 |
| 圆陷阱 (单位圆) | $\min ||z_n|-1|$ | 环状纹理 |
| 十字陷阱 | $\min(|x_n|, |y_n|)$ | 网格状纹理 |

### Python

```python
min_dist = np.full_like(Z, np.inf)
for n in range(max_iter):
    min_dist = np.minimum(min_dist, np.abs(Z))  # 点陷阱
    Z = Z*Z + 1/c
```

## 算法三: 距离估计 (Distance Estimation)

### 公式

$$D(c) \approx \frac{|z_n| \log |z_n|}{2^n |z_n'|}$$

其中 $z_n'$ 通过 $z_{n+1}' = 2z_n \cdot z_n'$ 同步迭代。

### 用途

让逆M水滴边界发出"光晕"——$D(c)$ 越小=越靠近边界。

### ⚠️ 逆M特殊处理

$1/c$ 项导致参数导数非零: $d(1/c)/dc = -1/c^2$。距离估计的导数递推与标准M不同，需重新推导。

## 逆M特有优势

标准M外部逃逸快、色彩单一。逆M水滴外部**缓慢逃逸**，$\mu$ 梯度丰富——标准M完全看不到的细腻渐变。
