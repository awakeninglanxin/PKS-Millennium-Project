# 12_阶段2几何重定位：PKS射影资产对函数域Weil模板

> 定位：承接 07（三方复审/D–H 测试）、08（全网扫描 + 路线图）、10（五处硬伤判定）、11_（阶段1 数值实验包）之后的**阶段 2 分析文档**。
>
> 一句话结论：PKS 想要的「用射影几何证明 RH」在**函数域上已经存在**（Weil 1948 曲线 / Deligne 1974 高维）。它的引擎是**算术侧对象**（Frobenius + ℓ-adic 上同调 + 交点正性），不是解析侧几何。PKS 初稿的射影资产（交比、临界圆、曲率、AFE）几乎全部落在模板的「解析部件」槽——而那个槽恰好是 Davenport–Heilbronn 型赝品也共享的槽。可迁移的只有一条路：把计算资产挂到 **Weil 二次型正性**（Connes 计划的数值核）上——这正是阶段 1 已在做的事。

## 一、模板：函数域 RH 为什么被证明

### 1.1 对象与陈述（以亏格 g 曲线 C/F_q 为例）

函数域上「RH」是 Weil 猜想的一部分。令 N_m = #C(F_{q^m})（有限域上的点数），则

$$N_m = q^m + 1 - \sum_{i=1}^{2g} \alpha_i^m,\qquad Z(t)=\frac{P(t)}{(1-t)(1-qt)},\quad P(t)=\prod_{i=1}^{2g}(1-\alpha_i t)\in\mathbb Z[t]$$

「RH」= 零点全在临界线 ⟺ 所有 Frobenius 本征值满足纯性（purity）：

$$|\alpha_i| = q^{1/2}\qquad\Longleftrightarrow\qquad |N_m-(q^m+1)| \le 2g\,q^{m/2}\ \ (\text{Hasse–Weil 界})$$

### 1.2 证明骨架（为什么算术侧自己会「证」RH）

| 构件 | 曲线情形（Weil 1948） | 高维情形（Deligne 1974） |
|------|------|------|
| 计数引擎 | 图(Frobenius) 与 对角线的交点 = N | Lefschetz 不动点公式 Tr(Fr\|H^i) 交错和 |
| 上同调载体 | C×C 上的除子/对应（Picard/Jacobian） | Grothendieck ℓ-adic 上同调 H^i(X) |
| 决定性不等式 | Hodge 指标定理 / Castelnuovo–Severi 不等式（曲面相交形式正性） | 硬 Lefschetz + 权（weight/purity）论证 |
| 函数方程的角色 | 只给 H^i ↔ H^{2n-i} 的对偶对称，**不给纯性** | 同左（次级角色） |
| 结论 | \|α_i\|=q^{1/2} ⇒ Hasse–Weil | \|α_{ij}\|=q^{i/2} ⇒ Weil 猜想全部 |

要点：**「零点在线上」不是函数方程推出来的**，而是上同调对象（携带定义在算术基域上的 Frobenius）加一个**几何正性不等式**推出来的。这正是 PKS 初稿最缺的东西——见 §三。

### 1.3 模板的四槽拆解

| 槽位 | 内容 | 函数域中的具体对象 | Spec Z（待建） |
|------|------|------|------|
| 槽1 算术引擎 | 有定义在基域上的端射/点计数 | Frobenius Fr，N_m = 点数 | 无（char 0，无 Frobenius）——Connes/Deninger 要造一个 |
| 槽2 上同调载体 | 谱对象承载 Fr | H^i(X, Q_ℓ)，Betti 数 = 多项式次数 | 未知（Deninger 算术上同调；Connes adèle 类空间） |
| 槽3 正性不等式 | 把计数界住的几何正性 | Hodge 指标 / C–S / 硬 Lefschetz | Weil 二次型正性（Connes：RH ⟺ Q(f)≥0） |
| 槽4 解析部件 | Γ 型因子 + 函数方程 | 伽马因子、ζ_C 的函数方程 | Γ(s/2)、AFE —— **这部分 Spec Z 已有** |

> ⚠️ 阶段1 的数值工作（11_）已经证明：槽3 在 Spec Z 的候选（Weil 二次型）**机制上可复现到 1e-14**——有限素幂 ≤ e^L 的算术数据精确等于零点谱侧。但那只验证了「槽1的有限截断 + 槽3候选的自洽性」，槽2（承载上同调）在 Spec Z 仍不存在。数值自洽 ≠ 槽2 存在。

## 二、D–H 判据的几何版：为什么「只动槽4」必然失败

07 文档的 Davenport–Heilbronn 测试在模板语言下有一个更锐利的表述：

> **槽4 是「共享槽」**：D–H 函数 f(s) 与 ζ 共享同型函数方程、同型 Γ 因子、同型 AFE，唯独缺 Euler 积（算术输入）。一切只用槽4（Γ/函数方程/AFE/Stirling/解析近似）的论证，若推出 ζ 的 RH，就同时推出 D–H 的 RH——已知为假。

几何翻译：**对「临界线的形状」做任何射影/共形/曲率几何（槽4 的几何化），都自动被 D–H 赝品复制**。因为 f 的临界线形状与 ζ 同款（同样的 Γ 因子决定同样的 θ(t) 与零点的相位几何）。PKS 初稿的 M2 平稳相位、B4 交比、悬链曲率分析全部落在此类。

由此得到阶段 2 的第一条筛选规则：

| 规则 | 内容 |
|------|------|
| R1 | 一个几何对象若只引用临界线/Γ 因子/函数方程上的结构，则它无算术载荷（D–H 可复制）→ 弃 |
| R2 | 一个几何对象若能回答「作用空间是什么 + 谱如何对应零点 + 算术输入在哪」，才进入候选 |
| R3 | 候选的算术输入必须能退化到「素数/点计数」级别（阶段1 引擎已经展示了这种输入长什么样） |

## 三、PKS 射影资产 × 模板槽位 映射表

| PKS 资产 | 初稿用途 | 模板槽位 | 判定 |
|------|------|------|------|
| 交比不变量 (A,B;C,D)（B4，w=e^s 临界圆） | 构造射影不变量逼近零点 | 槽4（临界圆=Γ 因子相位几何） | ❌ 恒=1 退化（10 硬伤②）；即使非退化也被 D–H 复制 |
| Riemann–Siegel 主和 + 平稳相位（M2） | 主和替换为「平稳区和」 | 槽4（ζ 的解析近似） | ❌ 对象错配 + 无平稳点（10 硬伤①）；D–H 同款近似 |
| AFE + Euler–Maclaurin 余项（M3–M4） | 误差控制 | 槽4（通用解析工具） | ❌ 误差与主项同阶（硬伤③）；无 Euler 积输入 |
| 悬链多边形曲率 κ∝1/s（对数螺线型） | 几何挑出 σ=1/2 | 槽4（临界带上的相位曲线族） | ❌ 曲线族与 σ 无关，σ 只进比例常数；D–H 同款 |
| M5 零点计数（log vs 幂） | 造矛盾 | 槽4 | ❌ 伪矛盾（硬伤⑤） |
| 蛋形/双曲线锥体/Schauberger 路径（04 文档） | 3D 几何「证明」 | 槽外（未定义作用空间） | ❌ 未回答 R2：几何作用在什么空间、自伴谱在哪 |
| **11_ 数值引擎（Weil 二次型对拍）** | 复现 Connes 机制 | **槽3 候选（数值侧）** | ✅ 唯一挂上模板的资产：Q(f)≥0 的有限截断自洽到 1e-14 |
| PKS 计算/工程能力（bat 自动化、谱系工具） | — | 槽2/槽3 的**数值支撑角色** | ✅ 可迁移：Connes 路线需要大量高精度谱计算 |

> 读表结论：**PKS 初稿的「几何」集中在槽4，而槽4 是死槽（R1）；初稿唯一「活」的资产不是它的几何，而是它的计算能力**——把计算能力对准槽3 候选（Weil 二次型正性的数值与谱分析），就是阶段1 已走通、阶段2 应加深的方向。

## 四、Spec Z 移植的已知困难（Connes 计划三十年卡在哪）

| 困难 | 内容 | 学界现状（截至 08 文档） |
|------|------|------|
| 无 Frobenius | char 0 没有有限域上的 Fr；需要「算术 Frobenius」 | Deninger：猜想 Θ 流/算子，谱=临界带，Γ 因子当「无穷素点」的行列式 |
| 无上同调 | Spec Z 没有 ℓ-adic 上同调可用 | Connes：adèle 类空间上的非交换几何 / 迹公式；Grothendieck 的 motive 之梦 |
| 无交点正性 | 没有曲面 C×C 可做 Hodge 指标 | Connes：Weil 二次型正性 = Riemann–Roch 正性的类比（RH ⟺ Q≥0） |
| 有限步可验的突破 | 需要「有限素数数据 → 无限零点」的收敛定理 | Connes 2026-02「致信黎曼」：素数≤13 → 前 50 零点，2.6e-55（08 已记录）；CCM 2025-11：素数 p≤x 造自伴算子，谱与最低零点重合 |

诚实的注记：Connes 2026-02 的 e^L=13 → 4.5e-14（我们的阶段1 对拍）与论文的 2.6e-55 之间差 40 个数量级，差的不是算力，是 **prolate 最优窗 + 区间算术**（README 下一步①）。即便如此，2.6e-55 仍是「有限素数确定有限零点」的数值证据，**不是槽2 的构造**——RH 依然开放。

## 五、可迁移的建设性候选（阶段 2 的可行子集）

按 R1–R3 筛选后，PKS 资产能迁移的方向收敛为三个，全部是**数值/谱学**性质的：

| 候选 | 内容 | 对应模板槽 | 前置条件 |
|------|------|------|------|
| A. prolate 窗谱分析 | 用 prolate spheroidal 基做 Weil 二次型极值化，逼近 Connes 2.6e-55 量级的截断（能到多少算多少，诚实标注） | 槽3 数值 | 阶段1 引擎 + scipy pro_ang1/mpmath 高精度 |
| B. 算术侧算子谱 vs 零点 | 把 03 的 B_arith 当截断自伴算子的 Gram 表示，扫其特征值并与零点前几位对照（Hilbert–Pólya 数值版） | 槽2/槽3 界面 | B_arith 在 N↑、L↑ 的极限行为 |
| C. 小窗 LW 曲线 | 扫 L→0，测算术侧受限算子最小特征值的衰减形状，对照 Chuk 8.9e-18 证书 | 槽3 数值 | 需 prolate + 区间算术才可做严格版（float64 只能给形状） |

以及一条**思想层面的重定位**（PKS 射影直觉的去向）：

> 若 PKS 的射影直觉要保留，正确的对象不是「临界线的射影几何」，而是**测试函数空间上的二次型 Q 的正锥/迷向锥几何**（无限维）。Weil 二次型 Q(f)≥0 在函数域对应 Riemann–Roch 正性——把「交比/圆锥曲线」的直觉翻译成「Hilbert 空间二次型的锥」的语言，才是与模板同构的几何。这是一条可以写成长文的路线，但不是数值实验。

## 六、判定总表

| 问题 | 答案 |
|------|------|
| PKS 初稿几何属于模板哪槽？ | 槽4（解析部件），全部可被 D–H 复制 |
| 初稿有槽1/槽2/槽3 的东西吗？ | 无（无 Euler 积、无上同调对象、无正性不等式） |
| 初稿五处硬伤在模板下是什么？ | 全部是「试图用槽4 推出槽3 结论」的必然失败 |
| PKS 还有可迁移资产吗？ | 有：计算/谱学能力 → 槽3 候选（Weil 二次型）数值支撑 |
| 阶段 2 该做什么？ | 候选 A/B/C 三个数值方向（见上），加一条思想重定位长文 |
| RH 状态变了吗？ | 没有。函数域已证；Spec Z 仍开放；本阶段只重定位，不声称证明 |

一句话：**PKS 的射影几何是正确答案放错了槽——函数域证明里的「射影几何」作用在算术曲面上（交点=计数），不是作用在临界线上（相位=解析）。把资产搬到正确的槽（Weil 二次型的谱分析）之后，PKS 的角色从「证明者」转为 Connes 路线上的计算贡献者——这是 08 路线图阶段 3 的入口。**
