# 11_Weil正定性数值实验 — 说明文档

> 阶段 1 数值转向的第一个实验包：复现 Connes 战略的核心机制——**有限素数截断的算术侧 ⟺ 零点谱侧（截断）**。
>
> 本实验包不声称证明任何东西，只做**诚实、可复现、有正确性自检**的数值验证。五件套：`01` Weil 显式公式 + 正定性扫描，`02` Li 系数流水线，`03` 算术侧 Weil 算子矩阵，`04` mpmath 高精度裁决。

---

## 一、数学背景（为什么这是"真实的战场"）

在 `07_黎曼假设_三方独立复审_DH测试.md` 里已经判定：PKS 的 M1–M6 框架是 reformulation，因为它**全程没有算术输入**（无 Euler 积 / 素数 / 互反律），通不过 Davenport–Heilbronn 测试。

而 Connes 战略（arXiv:2602.04022 + Connes–Consani prolate 论文）是**唯一同时满足「带算术输入」+「可数值验证」的活路线**。它的数学内核是 **Weil 显式公式**：

> **Weil 判据**：黎曼假设 ⟺ Weil 二次型 Q(f) ≥ 0 对所有适当的 test function f 成立。

关键是：当 test function 的支撑被限制在 $[e^{-L}, e^L]$ 时，算术侧**只含素数 $p \le e^L$ 的有限和**，却精确等于含**所有非平凡零点**的谱侧。

> 这意味着：**"只用前几个素数的信息" 与 "全部零点的信息" 在显式公式中等价**。有限素数截断的正定性，就是 RH 的有限片段。

---

## 二、核心公式（乘性 Fourier / Connes–Consani 归一化，已数值验证）

⚠️ **版本记录（2026-09-02）**：初版误用了 Bombieri Mellin 归一化（谱侧带 $e^{u/2}$、素数项系数 $\Lambda(p^k)$、常数项 $(\log4\pi+\gamma)h(0)$），与乘性 Fourier 谱侧混用导致 diff≈1.4 不可约。经 L=0.5（无素数）诊断后**切换到下方自洽版本**，三组 L 全部验证到 1e-7~1e-10。

对偶实 test function $h(u)$（支撑 $[-L,L]$，$u=\ln x$），定义偶 Fourier 变换：

$$\hat h(t) = \int_{-L}^{L} h(u)\,\cos(tu)\, du$$

**Weil 显式公式**（对共轭对 ρ 与 1-ρ̄ 归并后）：

$$2\sum_{\gamma>0}\hat h(\gamma) = \underbrace{2\int_{-L}^{L} h(u)\cosh(u/2)\,du}_{\text{main（谱主项）}} - \underbrace{2\sum_{p^m\le e^L}\frac{\ln p}{p^{m/2}}\,h(m\ln p)}_{\text{psum（有限素数项 ← 关键）}} + \underbrace{\frac{2}{\pi}\int_0^\infty \theta'(t)\,\hat h(t)\,dt}_{\text{arch（Archimedean 项）}}$$

其中 $\theta'(t)=\tfrac12\mathrm{Re}\,\psi(\tfrac14+\tfrac{it}{2})-\tfrac12\ln\pi$（Riemann–Siegel θ 的导数，用 digamma 计算），$\gamma$ 遍历非平凡零点虚部。

**Weil 二次型**（谱侧、正定性扫描用）：

$$Q_N(f) = 2\sum_{n\le N}|\hat h(\gamma_n)|^2 \;\ge\; 0$$

## 三、实验设计

| 脚本 | 实验 | 内容 | 验证目标 |
|------|------|------|----------|
| 01 | 实验 1 | 算术侧（main−psum+arch，只含 p≤e^L）vs 谱侧 2Σĥ(γ) | 显式公式自检，展示「有限素数 ⟺ 零点」 |
| 01 | 实验 2 | Q_N = 2Σ\|ĥ(γ_n)\|² 随 L/N 扫描 | 谱侧正定性（注意：Q 随 L 减小是能量集中，非 LW） |
| 01 | 实验 3 | Gram 矩阵 G_jk=2Σĥ_jĥ_k 最小特征值 | 固定采样点数下的数值秩饱和（非 Landau–Widom） |
| 02 | Li 流水线 | λ_n=Σ_ρ[1−(1−1/ρ)^n]，n=1..20 | Li 判据正值性 + λ_1 闭合值锚点 |
| 03 | 算术侧 Weil 算子矩阵 | B(j,k)=½A(h_j*h_k)（素数到 e^{2L}）vs 谱侧 Σ_γ ĥ_j(γ)ĥ_k(γ) | **算术数据复现谱侧 Gram（对拍 ~1e-16）** + 有限秩正定性 |
| 04 | 高精度裁决 | mpmath dps=40 重算算术侧 vs float64，扫 K×T_arch | 区分「求积噪声地板」与「Archimedean 截断」（归因修正） |

test function 族（**cos⁴ 窗，C³ 光滑、闭式 Fourier 变换**）：

$$h_k(u)=\cos^4\!\Big(\frac{\pi u}{2L}\Big)\cdot\cos\!\Big(\frac{\pi k u}{L}\Big),\qquad k=0,1,2,\dots$$

cos⁴ 窗保证 |ĥ(t)| ~ O(1/t⁴)（前三阶导数在 ±L 处消失），谱侧部分和绝对收敛。展开 cos⁴=(3+4cos+cos2)/8 后每个积分都是 ∫₀ᴸcos(ωu)du=sin(ωL)/ω 的有限组合 → **ĥ(t) 有解析闭式，无内层数值积分**（这是本实现可快速、稳定复现的关键）。

## 四、实测结果（2026-09-02 修正版，float64 + scipy，γ₁..γ₈₀₀）

**实验 1：显式公式自检（差值 = 谱尾截断 + Archimedean 截断，随 K、T_arch 收敛）**

⚠️ **归因修正（2026-09-02 晚间，04 号脚本裁决）**：早期版本默认 T_arch=150，导致 L≥2.0 残差卡在 ~1e-11 且不随 K 下降，当时误记为「float64 求积噪声地板」。**该归因作废**——mpmath dps=40（求积噪声已消除）在 T_arch=150 给出同样 ~1.17e-11，而 T_arch 提到 600 后 float64 与 mpmath 都降到 ~1e-13~1e-14 并开始随 K 收敛。真凶是 **Archimedean 项截断**，不是 float64。下表为更正后权威数据（T_arch=600，k=0，A = main−psum+arch）：

| L | e^L | 素幂 ≤ e^L | A(h) | \|A−谱侧\|(K=400) | \|A−谱侧\|(K=800) |
|------|------|------|------|------|------|
| 0.5 | 1.649 | 无（纯 Archimedean） | +6.616e-2 | 8.3e-11 | 5.8e-12 |
| 1.0 | 2.718 | 2 | +1.472e-3 | 2.2e-12 | 5.0e-12 |
| 1.5 | 4.482 | 2,4,3 | +1.654e-4 | 2.3e-13 | 5.3e-14 |
| 2.0 | 7.39 | 2,4,3,5,7 | −1.063e-5 | 5.0e-13 | 1.6e-13 |
| ln13≈2.565 | 13.0 | 2,4,8,3,9,5,7,11,13 | −2.462e-5 | 4.6e-14 | 4.5e-14 |

→ 六组 L 全部吻合，Connes 原初设定（e^L=13，素数≤13）对拍到 **4.5e-14**（早期 T_arch=150 报 4.0e-12，差 ~90 倍正是 arch 截断）。**素数系数 p^{m/2}（而非 p^m）被数值确认**——这是初版最大的归一化错误点。

⚠️ **关于 Landau–Widom 的澄清（2026-09-02 修正）**：LW 指数衰减指的是约束收紧方向——支撑窗变窄（L→0）时，**算术侧**受限算子的最小特征值 λ\*(L) 按指数趋零（Chuk 在 L=0.8 小窗给出证书 $Q(f)\ge 8.9\times10^{-18}$）。本实验包的谱侧 Q/Gram 与此**不是一回事**，只能当「引擎自检」的辅助观察，不能引作 LW 证据。

- **max|Δ| ~ 1e-16**：算术数据（素幂 ≤ e^{2L} 的 Von Mangoldt 项 + Archimedean 项）**精确复现谱侧 Gram**——这是「有限素数数据 ⟹ 零点平方和矩阵」的最直接数值展示，也是真正的 Q 正定性检验对象（区别于 01 的谱侧 Gram）。

## 五、诚实边界（本实验包不做什么）

1. **不证明 RH**——谱侧 Gram 是 FᵀF 型、正定性是构造性的；Q_N>0、λ_n>0 都是「与 RH 一致」的必要条件，非充分。
2. **不达到 Connes 的 $10^{-55}$ 精度**——那需要 60+ 位精度 + prolate spheroidal 函数 + 区间算术。本包用 float64 + cos⁴ 闭式基，目标是**复现机制 + 正确性自检**。
3. **双重截断**——谱侧用前 K 个零点求和（截断误差随 K 减小），Archimedean 项在 T_arch 截断（随 T_arch 减小而增大；01 默认已提到 600，残差 ~1e-14 量级）。
4. **zetazero() 默认零点在临界线上**——不能证伪 RH；这正是 Davenport–Heilbronn 判据要提醒的：数值自洽 ≠ 证明。
5. 若要在数值上真正逼近 Chuk (arXiv:2608.24827) 的 L=0.8 证书 $Q(f)\ge8.9\times10^{-18}\|f\|^2$，需换 prolate 基 + 区间算术（超出本包范围）。
